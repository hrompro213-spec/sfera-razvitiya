# Сфера Развития — лендинг

Сайт образовательного центра «Сфера Развития»: подготовка к ОГЭ и ВПР по русскому
языку и математике, нейротренировки, занятия онлайн (Zoom) и офлайн.

**Живой сайт:** https://sferarazv.ru

---

## Что это

Одностраничный лендинг без сборки и без внешних библиотек:

- **HTML** — `index.html` (лендинг) и три служебные страницы: `thank-you.html`,
  `privacy.html`, `consent.html`;
- **CSS** — один файл `styles.css`, всё оформление на CSS-переменных, есть светлая
  и тёмная тема;
- **JS** — один файл `app.js` (`defer`), только ванильный JS: тема, FAQ,
  аккордеоны секций, копирование заявки при клике по тарифу, сезонная картинка
  шапки, маска/валидация формы.

Никаких npm-зависимостей, сборщиков, препроцессоров и CDN-подключений. Тексты и
стили правятся прямо в файлах.

## Быстрый старт

1. Склонировать репозиторий:
   ```
   git clone https://github.com/hrompro213-spec/sfera-razvitiya.git
   cd sfera-razvitiya
   ```
2. Открыть `index.html` в браузере — сайт уже работает.

**Лучше через локальный сервер** (так корректно работают буфер обмена, `fetch` и
относительные пути):

- VS Code → расширение **Live Server** → «Open with Live Server»;
- или `python -m http.server 8000` → http://localhost:8000/.

При открытии через `file://` браузер может блокировать `navigator.clipboard` —
копирование текста тарифа и плашка «Сообщение скопировано» в этом случае просто
не сработают, остальной сайт работает.

## Публикация

Сайт публикуется **без сборки**: что лежит в ветке `main`, то и отдаётся.

- **Основной хостинг — GitHub Pages.** Домен `sferarazv.ru` привязан файлом
  `CNAME` в корне репозитория. Pages настроен на деплой из ветки `main`, корень
  (`/`) — GitHub Actions и сборка не используются.
- **GitLab — зеркало** (`https://gitlab.com/hrompro213/sfera-razvitiya.git`),
  публикация на домен идёт с GitHub.

Порядок выкладки:

```
git add .
git commit -m "краткое описание правки"
git push origin main      # GitHub → Pages → https://sferarazv.ru
git push gitlab main      # зеркало (по желанию)
```

Обновление домена занимает 1–2 минуты; при проблемах смотреть вкладку
**Actions / Pages** в настройках репозитория GitHub. Для проверки «что уехало»
удобно смотреть последний коммит в GitHub.

**Важно:** `ARHIV/` и `PROJECTS/` не публикуются и не коммитятся — они перечислены
в `.gitignore` вместе с `desktop.ini`, `*.docx`, `*.pdf`, `Thumbs.db`, `.DS_Store`.
Эти папки живут только на рабочей машине.

## Заявки и аналитика

Заявки с формы уходят в Google Таблицу через веб-приложение Google Apps Script, и на
каждую заявку приходит письмо (см. `NOTIFY_EMAILS`): код лежит в
[google-apps-script/](google-apps-script/Code.gs), URL веб-приложения — в константе
`FORM_ENDPOINT` в `app.js`. Деплой и обновление описаны в
[google-apps-script/README.md](google-apps-script/README.md).

На сайте подключён счётчик Яндекс.Метрики **114274834** (Вебвизор, карта кликов,
отслеживание внешних ссылок): код — в `<head>` у `index.html` и `thank-you.html`,
номер — в `METRIKA_COUNTER_ID` в `app.js`. Цели отправляются через
`reachAnalyticsGoal()`; перечень — в `ANALYTICS_GOALS`.

## Требования к правкам

- Без сторонних библиотек, шрифтов и CDN.
- Без инлайновых `style="…"` и `onclick="…"` — только классы и `app.js`.
- Иконки — SVG из спрайта в начале `<body>`, без эмодзи.
- Новые картинки — до 250 КБ; первый экран грузим сразу, остальное — `loading="lazy"`.
- Перед пушем: открыть страницу в браузере, проверить 1440 px и 390 px, тёмную
  тему и отсутствие горизонтального скролла.
