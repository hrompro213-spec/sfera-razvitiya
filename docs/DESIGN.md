# Дизайн-система и правила вёрстки

Версия 1.1 · обновлено 16.11.2026

Практическое руководство для тех, кто меняет `index.html`, `styles.css`, `app.js`:
сетка, компоненты, состояния, доступность и производительность. Смыслы и тон —
в [BRAND.md](BRAND.md), картинки — в [ASSETS.md](ASSETS.md).

**Стек:** статический сайт, HTML + CSS + ванильный JS, без сборки и без внешних
библиотек. Стили — один файл `styles.css`, всё оформление через CSS-переменные
в `:root` и `[data-theme="dark"]`.

## 1. Сетка и контейнер

| Что | Значение |
|---|---|
| Контейнер `.container` | `max-width: 1100px; margin: 0 auto; padding: 0 20px` |
| Шапка `.nav` | та же ширина 1100 px и отступы 12/20 |
| Hero | собственные отступы `90px 20px 70px` (на ≤560 px — `70px 18px 54px`) |
| Сетка карточек `.cards` | `repeat(auto-fit, minmax(280px, 1fr))`, gap 22 px |
| `.cards-2` / `.cards-3` | жёстко 2 / 3 колонки |
| Шаги `.steps` | `repeat(auto-fit, minmax(230px, 1fr))`, gap 18 px |
| Плашки доверия `.trust-grid` | `repeat(auto-fit, minmax(260px, 1fr))`, gap 20 px |
| Тарифы `.prices` / `.prices--3` | auto-fit 260 px / ровно 3 колонки, gap 22 px |
| Форма + контакты `.contact-layout` | `minmax(320px,1.15fr) minmax(280px,.85fr)`, gap 20 px |

**Брейкпоинты:** только два — `max-width: 900px` и `max-width: 560px`.
На 900 px: навигация переносится и центрируется, `cards-2/cards-3`, `prices`,
`contact-layout` схлопываются в одну колонку. На 560 px: кнопки `.btn`
становятся на всю ширину, hero уменьшает отступы, появляется `mobile-sticky-bar`,
скрывается `floating-widget` и QR, у body добавляется `padding-bottom: 78px`.

## 2. Вертикальный ритм

| Что | Значение |
|---|---|
| `section` | `padding: 60px 0` |
| Свёрнутая секция `.is-collapsible:not(.is-open)` | `padding: 36px 0`, у `.section-sub` — `margin-bottom: 0` |
| `#teacher` | `padding-top: 30px` (стык с `#format`) |
| `#format.is-open` | `padding-bottom: 30px` |
| Заголовок секции → подзаголовок | `margin-bottom: 14px` |
| Подзаголовок → контент | `margin-bottom: 40px` |
| Внутри карточек | padding 30×26 (карточка), 26×24 (шаг), 28×24 (trust), 34×26 (тариф) |

**Правило:** два блока с одинаковым фоном не должны стоять вплотную с двойным
отступом (60 + 60). Если секции идут подряд без смены фона — уменьшайте отступ
или разводите фоном (`--bg` / `--bg2` чередуются).

## 3. Компоненты

### 3.1. Карточка (`.card`, `.result-card`, `.audience-card`)

- **Где:** «Кому подойдёт», «Что получит ребёнок».
- **Как:** белая плашка, рамка `1px var(--line)`, радиус 18 px, тень `--shadow`,
  внутренние отступы 30×26; при наведении поднимается на 5 px (`translateY(-5px)`).
- **Главная карточка** `.audience-card--primary`: рамка 2 px `var(--gold)`, лёгкий
  золотой градиент по фону, увеличенные заголовок (`--fs-h3-lg`) и иконка.
- **Чего избегать:** больше одного акцентного варианта на экран; текста длиннее
  3–4 строк (длина ограничена `--measure`); иконок-эмодзи.

### 3.2. Кнопки

| Класс | Где | Вид |
|---|---|---|
| `.btn` | основное действие (MAX, «Отправить заявку») | золотой градиент, радиус 50 px, 18 px/800, padding 16×38 |
| `.btn.btn-lg` | hero и финальный CTA | 20 px, padding 18×46 |
| `.btn.btn-secondary` | второе действие на тёмном фоне (hero «Позвонить», «Оставить заявку») | полупрозрачная рамка и фон, белый текст; в `.cta-section` — рамка `--line`, текст `--gold2` |
| `.audience-card-cta` | внутри карточки ОГЭ | `inline-flex`, `width: auto`, отступ сверху 26 px |
| `.section-more` | дубль-кнопка аккордеона | маленькая пилюля 14 px, рамка `--line`, текст `--gold2` |
| `.cta-phone` | телефон в финальном блоке | крупная золотая ссылка 26–40 px |

- **Правила:** одна основная кнопка на блок; текст — глагол + объект; не больше
  4 слов; на мобильном кнопки растягиваются на всю ширину.
- **Чего избегать:** трёх кнопок в ряд, «кнопок-ссылок» без действия, синих
  акцентов.

### 3.3. Бейдж (`.badge`, `.badge--link`, `.age-badge`)

- **Где:** `badge` — над H1 («Предварительная запись…») и на служебных страницах;
  `age-badge` — возраст в карточках аудитории.
- **Как:** пилюля, фон `--gold` (в hero) или `rgba(200,150,47,.12)`, текст 13–15 px/700.
- **Интерактивный** `.badge--link`: ссылка, `min-height: 44px`, при наведении
  светлеет и приподнимается.
- **Чего избегать:** бейджа-кнопки без ссылки; больше двух бейджей на экран.

### 3.4. Чип (`.chip`)

- **Где:** инфобар под кнопками в hero (первый шаг / где / формат).
- **Как:** полупрозрачная плашка на фото, радиус 14 px, подпись `b` — 13 px,
  капс, золото `#f5d287`.
- **Чего избегать:** чипов как навигации и как кнопок — это только подсказки.

### 3.5. Тариф (`.price`)

- **Где:** секция «Цены», три карточки (индивидуально / VIP-группа / группа).
- **Как:** вся карточка — ссылка `<a class="price" data-tariff="…" target="_blank">`,
  `cursor: pointer`; hover — рамка `--gold` и подъём 5 px; `:focus-visible` —
  `outline: 3px solid var(--gold)`.
- **Логика:** по клику копируется текст заявки в буфер и показывается плашка;
  `selected_plan` уходит в скрытое поле формы.
- **Чего избегать:** вложенных ссылок и кнопок внутри карточки (нельзя), текста
  «подробнее» внутри.

### 3.6. Аккордеон секции (`.section-toggle`, `.section-chevron`, `.section-body`, `.section-more`)

- **Где:** `#results`, `#format`, `#trust` (класс `is-collapsible`).
- **Как:** заголовок h2 содержит `<button class="section-toggle" aria-expanded
  aria-controls="…-body">` + шеврон 22 px; контент — в `.section-body`
  (`max-height: 0; overflow: hidden; opacity: 0`). Раскрытие — JS: `max-height`
  0 → `scrollHeight`, 450 мс, затем `max-height: none`.
- **Состояния:** `is-open` на кнопке поворачивает шеврон на 180°; текст
  `.section-more` меняется на «Свернуть».
- **Без JS:** `.no-js` показывает контент и прячет шеврон с `.section-more`.
- **Чего избегать:** двух разных механик на одной странице (старая «первые 2 из N»
  удалена), вложенных аккордеонов, скрытия заголовка.

### 3.7. Плашка-уведомление (`.copy-toast`)

- **Где:** подтверждение копирования после клика по тарифу.
- **Как:** `position: fixed`, `z-index: 120`, слева внизу (20/20), ширина до 380 px,
  рамка `--line`, радиус 14 px, 14 px/700; на ≤560 px — по центру над липкой
  панелью (`bottom: 84px`). Показ — класс `is-visible`, автоскрытие 5 с.
- **Чего избегать:** перекрытия `mobile-sticky-bar` и `floating-widget`, модальных
  окон для мелких подтверждений, автозакрытия быстрее 4 с.

### 3.8. Формы (`.application-form`, `.form-field`, `.checkbox-field`)

- **Где:** секция «Контакты», форма записи.
- **Как:** карточка 26×24, поля в 2 колонки на десктопе (`.form-grid`), в одну на
  ≤560 px; инпуты — рамка `1px var(--line)`, радиус 14 px, padding 13×14,
  фокус — рамка `--gold` + мягкое кольцо `rgba(200,150,47,.16)`.
- **Валидация:** сообщение в `.form-message` (`aria-live="polite"`), кнопка
  `disabled` на время отправки (`opacity .72`, `cursor: wait`), honeypot-поле
  вынесено за экран.
- **Чего избегать:** плейсхолдера вместо `<label>`, валидации только на клиенте,
  ошибок без текста, красных рамок на всю форму.

### 3.9. Служебные блоки

| Класс | Где | Особенность |
|---|---|---|
| `.trust-card` | «Почему родители выбирают нас» | номер 01–03 золотом 13 px, заголовок 23 px |
| `.step` / `.step-num` | «Как проходят занятия» | номер шага 13 px, капс-стиль |
| `.faq-item` / `.faq-question` | FAQ (рендерится из JS) | `aria-expanded`, ответ на `max-height` |
| `.contact-links` | быстрые каналы связи | пилюли `min-height: 44px`, MAX — золотой заливкой |
| `.quick-contact` | низ страницы перед футером | мелкая подпись + строка ссылок 13 px |
| `.floating-widget` | правый нижний угол (>560 px) | 3 канала, `z-index: 90` |
| `.mobile-sticky-bar` | низ экрана (≤560 px) | 3 канала, `z-index: 95`, `body` получает `padding-bottom: 78px` |
| `.top-cta` / `--alt` / `--bottom` | верхний баннер, летняя полоса | `--alt` — главный баннер с золотым градиентом, `--bottom` — спокойная полоса `--bg2` |

## 4. Состояния

| Состояние | Как задаётся | Комментарий |
|---|---|---|
| Hover | `.card:hover` (-5 px), `.btn:hover` (-3 px), `a.price:hover` (рамка + -5 px), `.section-toggle:hover` (цвет `--gold2`), `.contact-links a:hover` (золотая заливка) | 150–200 мс, без «прыжков» больше 5 px |
| Focus-visible | `a.price:focus-visible` — `outline: 3px solid var(--gold); outline-offset: 3px`; `.section-toggle:focus-visible` — цвет `--gold2` | **долг:** у `.btn`, `.theme-btn`, `.copy-btn`, `.section-more` своего outline нет — добавлять при правках |
| Active | не задан | рекомендация: `transform: none` и лёгкое затемнение, чтобы клик чувствовался |
| Disabled | `.form-submit:disabled` — `opacity: .72; cursor: wait` | других disabled-состояний нет |
| Dark theme | `body[data-theme="dark"]`, переключение `.theme-btn`, выбор в `localStorage` (`sfera-theme`) | все цвета — только через токены, иначе тёмная тема «поедет» |

## 5. Доступность

- **Кликабельные зоны на мобильном — от 44 px.** Соответствуют: `.badge--link`
  (44 px по `min-height`, по факту 81 px из-за двух строк), `.contact-links a`
  (44 px), `.thank-actions a` (44 px), `.copy-btn` (49 px), поля формы (55 px),
  `.faq-question` (94 px). **Известные отклонения:** `.mobile-sticky-bar a` —
  42 px, `.section-more` — 42 px, `.theme-btn` — 34 px. Поднимать до 44 px при
  правках этих компонентов.
- **Аккордеоны:** кнопка с `aria-expanded` + `aria-controls`, контейнер с `id`;
  то же в FAQ (`role="region"`, `aria-labelledby`).
- **`alt`:** содержательные у фото преподавателя и QR-кода; у логотипа — название
  компании; декоративная картинка шапки — `alt=""` и `aria-hidden` у контейнера.
- **`aria-live`:** `.copy-toast` (`role="status"`), `.form-message` (`polite`).
- **`prefers-reduced-motion: reduce`:** отключает анимации аккордеона, шеврона и
  плашки; новые анимации обязаны это учитывать.
- **Контраст:** `--text` на `--bg` ≈ 15.4:1, `--muted` на `--bg` ≈ 6.7:1 — хорошо.
  `--gold2` на светлом фоне ≈ 3.6:1 — годится для крупного текста (от 23 px bold),
  но **не для мелких золотых ссылок**. Для мелкого золотого текста брать оттенок
  темнее (`#8a6118` даёт ≈ 5.2:1) или переводить текст в `--muted`.
- **Клавиатура:** все действия — на `<button>` и `<a>`; аккордеоны и тарифы
  доступны с Tab, ссылки тарифов открываются в новой вкладке
  (`target="_blank" rel="noopener"`).

## 6. Производительность

- **Без библиотек и без внешних шрифтов.** Стек — системные шрифты, `Inter`
  подхватывается, только если установлен. Никаких Google Fonts, jQuery, AOS,
  Font Awesome.
- **Картинки — до 250 КБ.** Сезонные кадры `images/hero/*.webp` — 1600×894,
  факт 76–102 КБ (было 38–221 КБ при 1920 px; пережато 16.11.2026). Логотипы
  `logo-light.png` / `logo-dark.png` — 22–23 КБ, 128 px при выводе 64 px.
  `teacher.jpg` — 1229×1536 (4:5), 189 КБ (было 169×142 px и 7 КБ).
  Вне нормы: `hero.jpg` 2.3 МБ (только дефолт/фолбэк шапки), `bg.jpg` 2 МБ
  (на сайте не используется), `teacher-source.jpg` 2.3 МБ (исходник фото, в
  вёрстку не встроен) — см. [ASSETS.md](ASSETS.md).
- **Lazy-load ниже первого экрана:** у QR-кода нет `loading="lazy"` — добавить.
  У `teacher.jpg` атрибут уже стоит (16.11.2026). Первый экран — наоборот:
  `loading="eager" fetchpriority="high"` + `width`/`height` (уже есть).
- **Нет CLS:** картинка шапки лежит в абсолютном слое `.hero-media`, высота секции
  задаётся контентом, у `<img>` прописаны `width`/`height` и `aspect-ratio`.
- **JS:** один файл `app.js` (`defer`), инициализация по `DOMContentLoaded`, без
  зависимостей; сторонние скрипты — только счётчик Метрики (сейчас заглушка).
- **CSS:** один файл, токены в `:root`, без препроцессоров.

## 7. Как не надо

- **Без эмодзи в интерфейсе.** Иконки — только SVG из спрайта в начале `<body>`
  (`icon-target`, `icon-book`, `icon-sprout`, `icon-brain`, `icon-check`,
  `icon-chart`, `icon-moon`, `icon-sun`, `icon-chevron`, `icon-lock`).
  Единственное исключение — символ `✦` в списках преподавателя.
- **Без фиолетово-синих градиентов** и холодного «айти»-света: палитра тёплая.
- **Без светящихся шаров, бликов и неоновых ореолов.**
- **Без стекломорфизма на каждом блоке:** полупрозрачность с blur допустима только
  в шапке, чипах и виджете.
- **Без градиентного текста:** в CSS остался мёртвый `.hero h1 span` с
  `background-clip: text` — при правках удалить, новые не добавлять.
- **Без анимаций дольше 500 мс** и без параллакса; не анимировать больше одного
  элемента за раз.
- **Без обещаний результата в текстах** — см. [BRAND.md](BRAND.md).
- **Без инлайновых `style="…"` и `onclick="…"`:** только классы и обработчики в
  `app.js`.
- **Без новых шрифтов, иконочных шрифтов и CDN-подключений.**

## 8. Технический долг (для следующих исполнителей)

- Неиспользуемые правила в `styles.css`: `.schedule`, `.day`, `.day .d`,
  `.day p`, `.max-details*`, `.price .old`, `.hero h1 span` — удалить после
  проверки, что классы не встречаются в HTML.
- Дубли стилей кнопок: `.collapse-toggle` заменён на `.section-more` — старые
  селекторы вычищать при следующей правке.
- `teacher.jpg` — заменён 16.11.2026: 1229×1536 (4:5) при выводе 380 px,
  `aspect-ratio: 4 / 5` + `object-fit: cover`; исходник `teacher-source.jpg`
  (2752×1536). Прежняя версия 169×142 px мылила.
- Логотипы — заменены на PNG с настоящей прозрачностью 16.11.2026
  (`logo-light.png` / `logo-dark.png`, `height: 64px` у `.logo img`); вектор SVG
  по-прежнему в приоритете — тогда `.logo img` можно оставить как есть.
- Мелкие кликабельные зоны (см. «Доступность») — поднять до 44 px.
