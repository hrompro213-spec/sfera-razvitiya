## 7. Предлагаемая схема переименования

Правило: `<назначение>-<уточнение>.<ext>`, только латиница, дефисы, без дат и
хешей. **Переименование логотипов отложено до получения вектора** (сейчас нет
смысла плодить переименования дважды).

| Сейчас | Предлагается | Комментарий |
|---|---|---|
| `images/hero.jpg` | `images/hero-default.jpg` | дефолт/фолбэк шапки |
| `images/bg.jpg` | `images/source-bg-gold.jpg` | мастер-файл под `bg-cta.webp` |
| `images/og-cover.jpg` | без изменений | уже по схеме |
| `images/logo_white.png` | `images/logo-light.png` | **после получения вектора**: «white» — это светлая подложка темы, имя путает |
| `images/logo_black.png` | `images/logo-dark.png` | **после получения вектора** |
| `images/teacher.jpg` | `images/teacher-portrait.jpg` | вместе с новым исходником 800×1000 |
| `images/max-qr.jpg` | `images/max-qr.png` | QR лучше в PNG без потерь |
| `images/hero/hero-<сезон>-<day-или-evening>.webp` | без изменений | уже по схеме |
| архив `0832dfcf…jpg` | `sphere-gold-01.jpg` | в архиве, вне репозитория |
| архив `42edeb3c…png` | `logo-dark-01.png` | в архиве, вне репозитория |
| архив `abe327da…png` | `logo-light-01.png` | в архиве, вне репозитория |

После переименования обязательно: обновить ссылки в `index.html`, `app.js`
(`CONTACT_CONFIG.max.qrImage`, `HERO_IMAGES`, `HERO_FALLBACK_IMAGE`), JSON-LD и
`og:image`/`twitter:image`.

## 8. Решения владельца (14.11.2026)

1. **Логотип:** запросить у Тани вектор (SVG) или PNG с настоящей прозрачностью.
   До получения — ничего не переименовывать и не перекрашивать.
2. **Фото преподавателя:** запросить исходник **минимум 800×1000** — сегодня.
   Размытое фото в блоке доверия работает против доверия.
3. **Архив BRAND:** вынесен из репозитория в `D:\sfera-brand-sources\BRAND`,
   Git LFS не используем.
4. **`bg.jpg`:** не удалять; сжат в `bg-cta.webp` (82 КБ) и подключён фоном
   блока `#contact` под оверлеем. Если владельцу не понравится — удалить
   `bg-cta.webp` и одну CSS-строку.
5. **Сезонная раскладка:** проверяет владелец по таблице раздела 2.
6. **Деплой:** GitHub Pages, ветка `main`, корень; GitLab — зеркало вручную.
7. **Ассистент «Сфера»:** свой виджет на ванильном JS, не сторонний чат-бот;
   согласие на обработку данных обязательно; сценарии — из FAQ и от Тани;
   не начинать раньше этапа 8 плана (см. [BACKLOG.md](BACKLOG.md)).
8. **Юридические данные:** нужны реквизиты оператора ПД (ИП/самозанятость, ИНН,
   адрес для обращений) — запросить у Тани, без них политика юридически пустая.
9. **OG-обложка:** отдельный `og-cover.jpg` 1200×630 до 300 КБ — сделано,
   пересобрать после получения вектора логотипа.
10. **Языки:** только русский, альтернатив не нужно.
