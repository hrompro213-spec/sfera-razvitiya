# Инвентаризация изображений

Версия 1.0 · обновлено 14.11.2026

Все картинки проекта. Данные получены измерением файлов (формат, пиксели, вес,
средний цвет и доля тёплых/синих/белых/тёмных пикселей). Визуально проверить
кадры владельцу стоит отдельно — ниже это отмечено.

Связанные документы: [BRAND.md](BRAND.md) (смыслы и палитра),
[DESIGN.md](DESIGN.md) (как картинки встраиваются в вёрстку).

## 5. Где что применить

| Что | Куда | Условия |
|---|---|---|
| Сезонные кадры `hero-*.webp` | шапка `#hero` | уже подключено через `HERO_IMAGES`; менять только имена файлов, список — в `app.js` |
| `hero.jpg` | `og:image`, фолбэк шапки | нужен ресайз до 1200×630 для соцсетей и вес ≤ 250 КБ |
| `bg.jpg` | фон секции (например, финальный CTA) | сейчас не используется; при подключении — затемняющий оверлей и вес ≤ 250 КБ |
| BRAND 03 / 13 / 14 | фон тёмной секции или блок «Почему мы» | только с оверлеем, текст поверх — белый |
| `logo_white.png` / `logo_black.png` | шапка, футер, письма | нужен SVG или PNG с прозрачностью; сейчас это JPEG с запечённым фоном |
| `teacher.jpg` | блок «Занятия ведёт педагог» | нужен исходник ≥ 600 px по длинной стороне, иначе мылит |
| `max-qr.jpg` | карточка MAX | ок как есть, добавить `loading="lazy"` |

## 7. Предлагаемая схема переименования

Правило: `<назначение>-<уточнение>.<ext>`, только латиница, дефисы, без дат и
хешей.

| Сейчас | Предлагается | Комментарий |
|---|---|---|
| `images/hero.jpg` | `images/hero-default.jpg` | дефолт/фолбэк шапки и OG-картинка |
| `images/bg.jpg` | `images/section-bg-gold.jpg` | после оптимизации или удаления |
| `images/logo_white.png` | `images/logo-light.png` | сейчас имя путает: «white» — это светлая подложка темы |
| `images/logo_black.png` | `images/logo-dark.png` | тёмная тема |
| `images/teacher.jpg` | `images/teacher-portrait.jpg` | |
| `images/max-qr.jpg` | `images/max-qr.png` | QR лучше в PNG без потерь |
| `images/hero/hero-<сезон>-<day-или-evening>.webp` | без изменений | уже по схеме |
| `images/BRAND/0832dfcf…jpg` | `images/source/sphere-gold-01.jpg` | исходники: `<сюжет>-<тон>-<номер>` |
| `images/BRAND/42edeb3c…png` | `images/source/logo-dark-01.png` | |
| `images/BRAND/abe327da…png` | `images/source/logo-light-01.png` | |

После переименования обязательно: обновить ссылки в `index.html`, `app.js`
(`CONTACT_CONFIG.max.qrImage`, `HERO_IMAGES`, `HERO_FALLBACK_IMAGE`), JSON-LD и
`og:image`/`twitter:image`.

## 8. Что нужно от владельца

1. Подтвердить, что BRAND-кадры — это один сюжет в разных цветах (по анализу —
   да), и какие из них считаются «каноническими» для сезонов.
2. Дать исходное фото преподавателя нормального размера.
3. Дать логотип в SVG (или PNG с прозрачностью) — сейчас оба файла с «запечённым»
   фоном.
4. Решить судьбу `images/BRAND/` (62.5 МБ): оставить в репозитории, вынести в
   архив или перевести на Git LFS.
