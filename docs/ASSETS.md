сферы, RGB прозрачных пикселей = 0 — поэтому ресайз идёт через
премультиплицированную альфу, иначе по краю сферы был бы тёмный ореол). Границы
содержимого по alpha > 16 — `(38, 6)…(1216, 1195)`, то есть 1178×1189 px.

Сборка (скрипт `ARHIV/build_sfera_icon.py`, вне репозитория):

- `images/sfera-icon-source.png` — рабочая копия источника байт в байт
  (sha256 `8c6297d1…`), сам `ARHIV` не меняется;
- `images/sfera-icon.png` — **1024×1024 RGBA, 1.68 МБ**: холст обрезан по
  содержимому, добавлено поле 6 % от большей стороны (71 px), кадр выровнен по
  центру и приведён к квадрату без растяжения, ресайз LANCZOS;
- `images/sfera-icon-512.png` (468 КБ), `sfera-icon-192.png` (73 КБ),
  `sfera-icon-96.png` (19 КБ) — из базового файла, альфа сохранена; имена не
  менялись, `srcset` в `index.html` (`96 1x` / `192 2x`) править не нужно;
- `favicon-16.png` (0.5 КБ), `favicon-32.png` (2.6 КБ), `favicon.ico`
  (3.0 КБ, внутри 16×16 и 32×32), `apple-touch-icon.png` (180×180, RGB,
  подложка #FAF7F1, знак 140 px по центру, поля 20 px — без чёрных углов).

**Упрощённый знак для 16/32 (решение владельца 17.11.2026).** Фотореалистичное
дерево в сфере на 16 px превращается в мутное пятно, поэтому favicon собирается
не из базового файла, а из отдельного упрощённого знака:

- `favicon-16.png` — **только золотая сфера** #C8962F (диск радиусом 498 в сетке
  1024, тонкая окантовка #A87B22), дерева нет: на 16 px оно всё равно сливается.
  Углы прозрачные, 81 % площади занимает диск;
- `favicon-32.png` — золотая сфера с кремовым деревом #FAF7F1: ствол, одна пара
  ветвей и одна пара корней, линии ≈2.4 px;
- `favicon.ico` содержит оба кадра: 16 — сфера, 32 — сфера с деревом.

Отвергнутые варианты: `line` (контур сферы, дерево золотом на прозрачном фоне),
`filled` (дерево и на 16 px), `detailed` (уменьшенная копия базового файла).
Лист сравнения «было → detailed → line → filled → sphere16», светлая и тёмная
тема, 32 px и 16 px с ×10: `ARHIV/sfera-icon-build/favicon-16-32-compare.png`.
Пересборка: `python ARHIV/build_sfera_icon.py --variant sphere16|filled|line|detailed`
(по умолчанию `sphere16`).
**При следующей замене знака упрощённый вариант нужно пересобрать вместе с
остальными — он не является уменьшенной копией базового файла.**

В вёрстке подключены только 96 и 192 (через `srcset`) и favicon/apple-touch в
`<head>`; базовый файл и исходник на страницу не грузятся.

**Проблемы:** `hero.jpg` 2.3 МБ (дефолт/фолбэк шапки, в ротации не участвует);
`bg.jpg` держим как исходник — на сайте используется только его WebP-версия;
`teacher-source.jpg` 2.3 МБ и `sfera-icon-source.png` 2.84 МБ — исходники, на
сайте не подключены (кандидаты на вынос из репозитория); базовый
`sfera-icon.png` 1.68 МБ на страницу не грузится, но лежит в git.
