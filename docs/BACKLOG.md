## 1. Запросы к Тане (готовые тексты)

### 1.1. Логотип — вектор

> Таня, привет! Нужен логотип в векторе: `.svg` (или, если вектора нет, `.png`
> с настоящей прозрачностью, без белой/чёрной подложки). Сейчас на сайте лежат
> растровые файлы, у которых фон «впечатан» в картинку — в тёмной теме вокруг
> знака виден прямоугольник. Нужны две версии: для светлого фона и для тёмного.
> Если есть исходник в Figma/Corel — подойдёт ссылка на файл, выгружу сам.

**Зачем:** заменить `logo_white.png` / `logo_black.png`, пересобрать
`og-cover.jpg` с векторным знаком, отдать логотип в письма и соцсети.
**До получения:** ничего не переименовываем и не перекрашиваем.

### 1.2. Фото преподавателя — срочно

> Таня, нужно исходное фото для блока «Занятия ведёт педагог»: горизонтальное
> или вертикальное, **минимум 800×1000 px** по длинной стороне, без сильной
> обработки. Сейчас в коде стоит файл 169×142 px — он растягивается и мылит,
> а это блок доверия. Если есть 2–3 варианта — пришли, выберу лучший кадр.

**Зачем:** `images/teacher.jpg` выводится размером 170×215 px. Текущий файл
меньше выводимого размера — фото выглядит размытым.

### 1.3. Юридические данные оператора ПД

> Таня, для политики конфиденциальности по 152-ФЗ нужны реквизиты оператора:
> статус (ИП / самозанятая / ООО), ФИО или название, ИНН, адрес для обращений
> и, если есть, e-mail для запросов по персональным данным. Без этих данных
> политика юридически пустая.

**Зачем:** обновить `privacy.html` и `consent.html`, добавить реквизиты в футер.
